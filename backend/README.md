# API仕様書(仮)

基本的にpostで動作し、毎回userprofieを受け取る

### １．緊急時
1. user.carがfalseのユーザーから、postにアクセスされる(ここで非同期通信なので一時停止)
2. user.carがtrueのユーザーが、起動時に毎回ルートを叩きフラグを確認する。緊急時であることを確認し、緊急時であることを示す数値やbooleanを返す
3. 2.の情報により通知に表示されるボタン(緊急要請を受けるか受けないか)が押されてapiが叩かれる。1.で止まっていた処理を動かし始めるためにフラグなどを書き換える
4. 3.の処理により、1.で止まっていた処理が再開する

### ２．予約時
1. user.carがfalseのユーザーから、postにアクセスされる(予約申請の処理)
2. user.carがtrueのユーザーが、数秒毎にルートを叩きフラグを確認する。予約されたことを確認し、予約されたことを示す数値やbooleanを返す
3. 2.の情報により予約画面に予約が追加される、それを受けるボタンを押した場合apiが叩かれる
4.  user.carがfalseのユーザーも、数秒毎にルートを叩きフラグを確認する。予約が承認されたことを確認し返す
