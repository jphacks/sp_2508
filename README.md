## 製品概要
### 背景(製品開発のきっかけ、課題等）
「夏は自転車で通学するけど雪がある冬は車がある人を頼りたい」「バスに乗り遅れた」、「寝坊で遅刻しそう」「車持ってる人助けてほしい！」そんなとき、私たちは様々なSNSを用いて乗せてくれる人を探す。しかし、SNSでは情報が流れやすく、誰が本当に近くにいて、いつ出発するのか分かりにくい。個別に連絡を取るのも手間で、返信が遅れると結局間に合わないこともある。そんな不便さを解消するために、位置情報や時間、目的地をもとに、近くにいる友人と手軽にマッチングできる仕組みが求められている。信頼できる関係の中で気軽に助け合えるようなサービスがあれば、「ちょっと乗せて！」の一言がもっと自然に、そしてスムーズにできるようになるだろう。


### 製品説明（具体的な製品の説明）
### 特長
#### 1. 特長1　　緊急依頼機能
急な悪天候や寝坊、交通手段を逃したときでも、ワンタップで友人に「乗せて！」を依頼できる。友人全員へ自動通知し、素早く助けを求められる。

#### 2. 特長2　   予約機能
通学やサークル活動など、あらかじめ予定が分かっている場合に、出発時間や目的地を登録して乗り合いを予約できる。事前に調整ができ、無駄な連絡を減らす。

### 解決出来ること
車で送迎をお願いしたいけど、誰にどの手段で頼めば来てもらえるかわからない。
車に乗せてもらったけど、お礼が曖昧になってしまう

### 今後の展望
現段階では、友人の車に乗せてもらうハードルを下げることができたが、ガソリン代のやり取りやお礼の伝え方など、気を使う場面が多く存在しているので、お礼などを伝える機能の実装が出来れば、より便利なツールになると考える。また、ドライバーが依頼を受けると地図上に依頼の出発点が出るようにしていくことで、見やすいアプリになると考える。

### 注力したこと（こだわり等）
このサービスで注力したのは、「頼みやすさ」と「気まずさの解消」である。
大学生や友人同士の間では、「頼みたいけど迷惑かな」といった心理的な壁が生まれやすい。そこで、簡単に依頼できるシンプルなUIを設け、気軽に助け合える環境づくりにこだわった。
